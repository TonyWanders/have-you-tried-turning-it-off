A program that writes one funny tech support line to `/output/entry.txt`,
for the make.fun competition
[Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 134 characters, inside the 1 to 199 gate.

## The line

```
Have you tried turning it off and on again? It fixed my toaster, my marriage is still loading, and your business is next in the queue.
```
